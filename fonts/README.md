# Fonts

Served from this folder so the page needs no third-party font request.

- `bricolage-grotesque*.woff2`: Bricolage Grotesque (variable weight 200–800), by Mathieu Triay. SIL Open Font License 1.1.
- `caveat*.woff2`: Caveat (variable weight 400–700), by Impallari Type. SIL Open Font License 1.1. Cut down to the letters, digits and signs the sales-book drawing uses.

The `-naira` files hold only the ₦ sign.
